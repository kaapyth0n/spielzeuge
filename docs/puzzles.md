# Animal puzzles

Route `/puzzles/`. Real local Commons photographs, 26 animals: 5 pets, 15 farm animals (cattle, goats, chickens, domestic pigs, sheep), 6 wild animals (lions, red deer). Each family is female → male → young, separate puzzles and distinct photos. Adult/baby source captions recorded in `public/puzzles/manifest.json`. Families describe animal roles, not actual kinship between photographs. Rabbit family and wild boar family are deferred rather than inventing sex-specific photographs.

Two halves, then one half and two quarters, then four quarters. Ghost image, generous 15px drag tolerance, tap-select/tap-place, keyboard Enter/Space, pointer-cancel and Escape. Wrong placements are gentle and never penalized. No clock. Completed photograph is unbroken; explicit Next, Again and Listen. All levels are open. Each world's current index persists; reset affects only that world and confirms. Mute stops both audio and speech and persists. RU/DE/EN and shared `spielzeuge.lang`; all labels and fallback text localized. Audio and obsolete speech stop on language change, next/restart/world selection, mute, home, pagehide and hidden document. BFCache pageshow re-enables gameplay.

Speech and real recordings are requested in the completing user gesture (voice availability/device audio permission vary). Quiet species and babies have narration only, no fake sound. No microphone, account, network media, ads, score or tracking. Images download locally at build time; no runtime hotlinks. Image failure displays a retry action. Photos fit without distortion or animal clipping; neutral margins are deliberate.

Checks: `npm run build`; `npm test -- --maxWorkers=1 --testTimeout=30000`; owned server `npm run dev -- --port 5182 --strictPort`, then `npm run test:puzzles`. Browser suite covers 390×844, 320×568, 844×390, 768×1024, 1366×900, 2/3/4 solving, real pointer drag, wrong placement/cancellation, family order, replay, translations/speech requests, mute persistence, progress persistence and retained-document departure. Screenshots in `artifacts/puzzles/` are review artifacts, not production assets. Physical iOS/Safari and audible voice quality not tested by Chromium automation.
