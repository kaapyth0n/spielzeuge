# Чуняшка

Calm dress-up toy. The doll is **always** in a full onesie. Clothes, shoes, hair, and face layer on top. There is no nude state.

Clothes are not only dresses: coats, overalls, sweaters, raincoats, jumpsuits, tunics, sailor suits — at least 20 pieces, plus 20 shoes. Hair has several cuts and colours. Eyes, brows, smile, and cheeks are separate.

Tap **Готово / Fertig / Ready**. Hearts count to a number that depends on the combo. Same look → same likes. Nothing is uploaded.

Language is the shared catalog lamp (`spielzeuge.lang`, `?lang=ru|de|en`).
